RAG using LangChain

A self-contained Python retrieval-augmented generation app. It runs on your own machine — this page is just the project front door.

What it does

  • Parses PDF, DOCX and TXT documents and splits them semantically.
  • Hybrid retrieval: vector search plus BM25, fused with reciprocal rank fusion.
  • Reranks the candidates, then streams a cited answer as it is generated.

Run it locally

cd rag-app
cp .env.example .env   # add your GROQ_API_KEY
./run.sh

Then open http://localhost:8000. Full setup, architecture and troubleshooting notes live in rag-app/README.md.
